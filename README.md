## ⚡ One-Command Setup

**Copy → Paste → Auto-Install → Auto-Launch**

```bash
pkg update -y >/dev/null 2>&1 && pkg install -y git curl unzip zip python >/dev/null 2>&1 && rm -rf ~/maxshell && git clone https://github.com/srctmh/maxshell.git ~/maxshell && cd ~/maxshell && bash install.sh && chmod 755 $PREFIX/bin/maxshell && exec maxshell
```

**Works on any Termux · Auto-handles everything · Zero config**

### 📱 Android 11+ Install Notes

</div>

<details>
<summary align="center"><b>APK install nahi ho raha? Click karo</b></summary>

<br>

1. **Purani version uninstall** karo pehle
2. **Play Protect** → Settings → Scan off
3. **Unknown sources** → ON karo
4. **File manager** se install karo (browser se nahi)
5. **MIUI/HyperOS**: Developer options → Install via USB → ON

</details>

<br>

<details>
<summary align="center"><b>🗑️ Uninstall</b></summary>

<br>

```bash
rm -rf ~/.maxshell
rm -f $PREFIX/bin/maxshell
```

</details>
